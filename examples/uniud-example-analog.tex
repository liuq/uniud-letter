% ESEMPIO 2 / DOCUMENTAZIONE
% Lettera istituzionale analogica.
%
% L'esempio è una lettera auto-documentante. Mostra soprattutto le differenze
% rispetto alla modalità digitale: il protocollo viene compilato con i campi
% tradizionali numero/titolo/classe/fascicolo.
% -----------------------------------------------------------------------------
\documentclass{uniudletter}

\usepackage{polyglossia}
\setmainlanguage{italian}
\usepackage{metalogo}
\usepackage{xcolor}
\usepackage{listings}

\definecolor{UniudCodeComment}{cmyk}{0,0.81,1,0.60}
\definecolor{UniudCodeKeyword}{cmyk}{0.64,0,0.95,0.40}
\definecolor{UniudCodeIdentifier}{cmyk}{0.62,0.57,0.23,0}
\lstset{
  basicstyle=\ttfamily\small,
  keywordstyle=\color{UniudCodeKeyword},
  identifierstyle=\color{UniudCodeIdentifier}\bfseries,
  stringstyle=\color{blue},
  commentstyle=\color{UniudCodeComment},
  morecomment=[l][\color{UniudCodeComment}]{\#},
  breaklines=true,
  columns=fullflexible,
  language=TeX
}

\UniudIstituzionale
\UniudAnalogico

\UniudSetup{
  struttura = {Area / Ufficio di esempio},
  indirizzo = {via Palladio 8},
  cap = 33100,
  citta = Udine,
  provincia = UD,
  paese = Italia,

  sito = {uniud.it},

}

\UniudProtocollo{
  numero = {4},
  titolo = {14},

  fascicolo = {1}
}

\UniudDestinatario{
  nome = {Spett.li Utenti \LaTeX},
  struttura = {Università degli Studi di Udine},
  indirizzo = {Loro sedi},
  citta = {Udine}
}

\UniudOggetto{Come scrivere una lettera istituzionale analogica con uniudletter}

\begin{document}
\begin{letter}{}
\opening{Gentili signore e gentili signori,}

la modalità analogica usa la stessa interfaccia della lettera digitale. La
differenza fondamentale è il blocco di protocollo, predisposto per i campi
tradizionalmente compilati sulla carta o nel flusso amministrativo associato.

Il prologo minimo è:

\begin{lstlisting}
\documentclass{uniudletter}
\usepackage{polyglossia}
\setmainlanguage{italian}

\UniudIstituzionale
\UniudAnalogico
\end{lstlisting}

\lstinline|\UniudAnalogico| sostituisce quindi
\lstinline|\UniudDigitale|. Tutti gli altri dati del mittente continuano a
essere impostati con \lstinline|\UniudSetup|:

\begin{lstlisting}
\UniudSetup{
  struttura = {Area / Ufficio di esempio},
  indirizzo = {via Palladio 8},
  cap = 33100,
  citta = Udine,
  provincia = UD,
  paese = Italia,
  telefono = {+39 0432 556111},
  email = {ufficio.esempio@uniud.it},
  sito = {uniud.it},
  firmatario = {Nome Cognome},
  ruolo = {Funzione}
}
\end{lstlisting}

Anche nella lettera analogica \texttt{telefono}, \texttt{email} e
\texttt{sito} sono liberamente impostabili. La classe non impone che siano
contatti generali della struttura: chi prepara la lettera può indicare i
riferimenti effettivamente utili al destinatario. È disponibile anche
\texttt{fax}.

Nella carta istituzionale i blocchi footer dei contatti e dei dati fiscali sono
attivi per default. Si controllano come unita' con
\texttt{footer-contatti=true|false} e \texttt{footer-fiscale=true|false};
responsabile e compilatore formano invece un unico blocco automatico.

Il protocollo analogico si imposta con un comando dedicato:

\begin{lstlisting}
\UniudProtocollo{
  numero = {4},
  titolo = {14},
  classe = {2},
  fascicolo = {1}
}
\end{lstlisting}

Le quattro chiavi corrispondono ai campi \texttt{Prot.}, \texttt{Tit.},
\texttt{cl.} e \texttt{Fasc.} del modello analogico. Se un campo non serve,
può essere lasciato vuoto.

Destinatario e oggetto si definiscono come nella modalità digitale:

\begin{lstlisting}
\UniudDestinatario{
  nome = {Prof.ssa Nome Cognome},
  struttura = {Università di esempio},
  indirizzo = {via Esempio 1},
  cap = 00100,
  citta = Roma,
  provincia = RM,
  paese = Italia
}

\UniudOggetto{Oggetto della comunicazione}
\end{lstlisting}

Il corpo della lettera non cambia:

\begin{lstlisting}
\begin{document}
\begin{letter}{}
\opening{Gentile Professoressa,}

Testo della lettera.

\UniudFirma
\end{letter}
\end{document}
\end{lstlisting}

Per passare da questo esempio alla versione digitale è quindi sufficiente
sostituire \lstinline|\UniudAnalogico| con \lstinline|\UniudDigitale| e
rimuovere, se non necessario, il blocco \lstinline|\UniudProtocollo|.

\UniudFirma
\end{letter}
\end{document}
